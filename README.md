# dsh-tinnitus · 耳鸣

DSH 的一条「耳鸣」副线：右耳里那声高频一直没停，越安静越响；听人说话会捞不全尾音，偶尔得让人再说一遍。
默认**不开**（`defaultEnabled: false`），要在这个会话里说得上这回事，用工具 `tinnitus_on` / `tinnitus_worse` / `tinnitus_relief`。

## 它到底做什么

- 每个会话一份身体状态，存在 `$DSH_HOME/dsh-tinnitus/sessions/<sid>.json`
- 每轮按配置算时长（默认 12 分钟一轮）攒「难受值」
- 到 `startAt`（默认 34）开始有可感知的注入；到 `flareAt`（默认 76）有 `flareChance` 的概率发作
- 注入只写**感受与说话要求**，不写解剖细节；平静时一个字都不注入
- 同一个状态有冷却（默认 8 分钟），发作 / 刚处理完不受冷却限制

## 语言方式（和其他插件不一样的地方）

不演疼，演**听错**：允许把一句话听岔、重复一个词、先按听到的半句作答再补后半句；`eeriness` 默认 3，允许出现不属于台词的碎片。

## 工具

| 工具 | 用途 |
|---|---|
| `tinnitus_on` / `tinnitus_off` | 开关这个会话的副线 |
| `tinnitus_status` | 读当前会话状态 |
| `tinnitus_relief` | 处理一下：开点白噪音 / 换个环境 / 揉一揉耳后 |
| `tinnitus_worse` | 主动加重（默认一轮的量） |

## 配置要点

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 总闸 |
| `defaultEnabled` | false | 新会话默认开不开 |
| `eeriness` | 3 | 语气不对劲的上限 0–3 |
| `gain` | 0.26 | 每轮加重 |
| `flareChance` | 0.24 | 到线后每轮发作概率 |
| `startAt` / `flareAt` | 34 / 76 | 有感觉 / 快发作 |

## 面板

侧边栏会多一格「耳鸣」，点开是一块面板页：

- 此刻的难受度（耳鸣）、刻着 `startAt` / `flareAt` 的刻度条、烦躁 / 发作次数 / 参与轮次 / 上次注入
- 最近这一路的曲线（实线难受度、虚线烦躁，最多 180 个点，面板开着每 15 秒记一个）
- 动手：开关这条副线、按 5 / 12 / 30 分钟加重、按缓解方式处理一下、把状态清回一开始
- 这个病怎么表现（平静 / 隐痛 / 发作三档原文）与它自己的语言方式

安静时更响，听人说话容易听岔。
面板读的是引擎自己落的 `sessions/*.json`，改状态走同一份运行时缓存，不绕过引擎。没有 `webServer`（纯 CLI）时面板不存在，插件照常工作。

## 卸载

从 profile 的 bundles 里移除 `dsh-tinnitus`，再删 `$DSH_HOME/dsh-tinnitus`。

> 只产出源码，本机未安装。
